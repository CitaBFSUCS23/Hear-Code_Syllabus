# 听声译码：音乐 + 编程跨学科课程设计方案

> **音乐是可感知的代码，代码是形式化的音乐。**

「听声译码」是一套以 MIT 开发的 [`music21`](https://web.mit.edu/music21/) 工具包为载体的高中 / 本科跨学科课程设计方案。课程把**乐理结构**与**程序结构**一一对应，让学生在「写代码 → 听音乐 → 改代码」的循环中，同时学习音乐与编程。课程采用项目式学习（PBL），共 16 节课，配套完整的教师资源包（含可运行的 Python 示例与 MusicXML 乐谱）。

- 教学对象：高二选修 / 本科音乐学院通选
- 单课时长：90 分钟（高中段可拆分为两堂 45 分钟）
- 核心技术：`Python 3.9+` + `music21`
- 课程类型：跨学科项目式学习

---

## 一、项目简介

课程以「用 Python 创作音乐」为任务主线，将音乐创作作为编程的真实情境，以代码作为音乐分析的工具。

- **核心创意**：把反复 ↔ 循环、乐句 ↔ 函数、卡农 ↔ 递归、转调 ↔ 映射、和弦 ↔ 数据结构等概念建立映射，让两个学科互相照亮。
- **两条轨道**：
  - **高中选修**：完成 10 节核心课（1–5、8–10、13、16），重点掌握数据化音乐表达、控制流、函数、并发模型与数据结构。
  - **本科通选**：完成全部 16 课，深入递归、高阶函数、马尔可夫链与面向对象编程（OOP）。
- **标注 ★ 的课次**为进阶内容，可视学情选学 / 跳过。

| 数学 | 十二平均律等比数列、时值分数运算、模 12 运算、组合数学、概率统计、线性插值、马尔可夫链与条件概率、分形与递归 |
| 艺术与人文 | 音乐情感与审美、自我认同、中外音乐文化、AI 创作伦理、设计思维、协作表达 |

### 3. 课程方案总览图

- `模块一` 声音与计算的基础——从音高数据到图灵机模型
- `模块二` 结构与并发——从函数封装到多线程多进程
- `模块三` 算法的旋律——数学、逻辑与音乐生成
- `模块四` 创作的计算——风格建模、面向对象与综合项目

### 环境配置

```bash
# 安装 music21
pip install music21

# 首次使用时在 Python 中配置 MuseScore 路径
from music21 import *
environment.set('musescoreDirectPNGPath', 'Path to /MuseScore4.exe')
environment.set('musicxmlPath', 'Path to /MuseScore4.exe')

# 验证安装
from music21 import note
n = note.Note("C4")
n.show()          # 在 MuseScore 中显示乐谱
n.show('midi')    # 播放 MIDI
```

运行教师资源包中的示例代码：

cd 教师资源包/第01课-音高的数字本质
python lesson01_pitch_numbers.py

## 七、跨学科设计亮点

1. **音乐作为内容**：从「感性接触」到「结构理解」。
2. **编程作为工具**：从「控制台输出」到「创造性表达」。
3. **数学作为桥梁**：从「公式记忆」到「结构感知」。
4. **计算音乐学**：从「消费者」到「研究者」。
5. **双重反馈机制**：逻辑判断与审美判断并行。
6. **设计思维贯穿始终**：迭代、优化、表达。
